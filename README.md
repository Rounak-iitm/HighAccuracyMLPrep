# HighAccuracyMLPrep

Production-grade Python library designed to bridge the gap between messy, raw, real-world data and high-accuracy machine learning models.

## Core Features
- Structural Type Detection
- Leakage-Free Imputation
- Advanced Feature Engineering
- Signal Pruning via LightGBM
- Dynamic Hyperparameter Profiling

## Demo
Upload a raw CSV file, select the target column, and the app will clean the data, build engineered features, train a model, and show validation metrics.
